# 3 分钟演示脚本 + 用户试用记录（v1.0）

> 用途：① 自己录演示视频或现场答辩时照着走；② 按方案 §10 验收 #5 找 5 个真实用户试用并记录。
> 前置：`powershell -ExecutionPolicy Bypass -File scripts/start.ps1`，浏览器打开 `http://127.0.0.1:8000`。
> 手机演示：`scripts\start-https.ps1` → 手机同一 Wi-Fi 打开 `https://<电脑IP>:8443`（装 `certs/ca.pem` 或点「继续前往」→ 允许相机 → 浏览器菜单「添加到主屏幕」）。

---

## 一、3 分钟演示（时间轴）

| 时间 | 动作 | 台词（照读） | 画面要点 |
|---|---|---|---|
| 0:00–0:20 | 打开页面，示意取景框 | "拍摄现场最难的不是相机，是不知道现在该怎么调。我们让 AI 看着你的画面，直接告诉你动作。" | 页面：一个主按钮、一个输入框、一个建议区（验收 #1）；右上角状态"相机就绪"或"演示模式" |
| 0:20–0:45 | 输入意图："电影感人物特写，背景虚化"，点主按钮 | "我不需要选模式，说人话就行。" | 抓帧 → 建议卡片 3 张，每条 = 动作 + 一句为什么（验收 #2/#3）；默认看不到分数 |
| 0:45–1:20 | 点第 1 条卡片"已按此调整"，走动/换机位后再点主按钮 | "它说后退两步，我照着做，再点一次——" | 分数变化（调试开关里可看，现场可不看），新建议刷新；卡片"有用"反馈 |
| 1:20–1:45 | 点"对比"，展示调整前 vs 调整后 | "左边是调整前，右边是调整后，这张对比图可以导出。" | 并排对比图 + 下载 PNG（验收 #4） |
| 1:45–2:10 | 点"记录镜头"两次，展示 before/after 缩略图与 clip_id | "每个镜头拍了什么、有没有按建议改，系统都记下来了。" | 落盘 `output/shot_log.csv` + 前后图 |
| 2:10–2:50 | 点"结束拍摄，生成粗剪" | "拍完不用从零整理：它把废片剔掉、按叙事顺序排好，给出转场和每条保留的理由。" | 整理统计（总/可用/剔除/重复 + 剔除理由）→ 时间线表格 → 总时长；"按建议调整过"出现在保留理由里（验收 #6/#7） |
| 2:50–3:00 | 点"下载 EDL/FFmpeg 命令" | "导入剪映或 FFmpeg 就能接着剪，我们只做最难的那一步。" | 下载 `.json` / `.bat`；说明本机没有 ffmpeg 时只导出命令 |

**演示兜底**：没有摄像头 → 自动进演示模式，点选内置场景图（逆光人像 / 杂乱背景 / 产品 / 风光）；服务起不来 → 说明启动步骤与 `docs/ACCEPTANCE.md` 的测试结果。

## 二、5 人试用记录表（验收 #5）

试用方式：每人 10 分钟，先自己用（不给讲解），再看 3 分钟演示。记录原话，不要诱导。

| # | 试用者（身份/拍摄经验） | 用到的意图 | 首条建议 | 他/她是否照做 | 原话（是否"想不到但有用"） | 评分 1–5 | 问题/建议 |

**通过线（方案 §10 #5）**：≥3 人说"这个建议我平时想不到，但确实有用"。
**同时记录**：每个人第一次按按钮到看到建议的秒数（目标 <5s）、是否追问"这是什么意思"（追问即话术不达标，反馈给 domain 改 `phrases.json`）。
